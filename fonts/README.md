# Fonts

Bundled fonts used for SVG badge vectorization. All text is converted to `<path>` curves
so the output SVGs are font-independent and render identically on all platforms.

## Roboto (Apache 2.0)
- `Roboto-Medium.ttf` — primary font for badge text (9px)
- `Roboto-Light.ttf` — secondary weight for Dolby sub-labels

Source: https://fonts.google.com/specimen/Roboto
License: Apache License 2.0

## Noto Sans (SIL Open Font License 1.1)
- `NotoSans-Regular.ttf` — Latin/Cyrillic/Greek fallback
- `NotoSansArabic-Regular.ttf` — Arabic script
- `NotoSansHebrew-Regular.ttf` — Hebrew script
- `NotoSansBengali-Regular.ttf` — Bengali script
- `NotoSansDevanagari-Regular.ttf` — Devanagari script (Hindi)
- `NotoSansThai-Regular.ttf` — Thai script
- `NotoSansCJK-Regular.ttc` — Chinese, Japanese, Korean

Source: https://fonts.google.com/noto
License: SIL Open Font License 1.1
