Install in Nuvio

  1. Pick Player or Source under Context, choose your badges and copy the URL.
  2. NuvioTV: open Settings › Layout › Streams › Fusion badge URLs, scan the QR code with your phone and paste the URL on the page that opens.
  3. NuvioMobile: open Settings › Layout › Streams › Fusion badge URLs, paste the URL and import it.

Use a separate set for each context

Player and Source badges match different things, so import two URLs:

  • Source for the stream list. It reads file and stream names and shows every tag it finds.
  • Player for the player. It reads what the decoder actually plays (resolution, HDR, audio format, channels, audio language) and uses names only for what a decoder cannot report, like the source or network.
  1. Import the Player URL first, then the Source URL. The last imported URL becomes active and is used in the stream list. You can switch the active URL later in the same list.
  2. Turn on Show in player, open Player badges and pick the Player URL.

Nuvio keeps up to 3 URLs and stores a copy of the badges, so import a URL again after you change it here.
